A parser for the [Minecraft anvil file format](https://minecraft.wiki/w/Anvil_file_format).
This package is a **fork** of **0xTiger's anvil-parser**, which was itself originally forked from [matcool's anvil-parser](https://github.com/matcool/anvil-parser). The original fork by 0xTiger aimed to add support for Minecraft versions **1.18 and above**. Our current version continues this development for project needs.
